
# RGB Image Channel Manipulation

## Project Overview
This project demonstrates how to manipulate individual Red, Green and Blue (RGB) colour channels of an image using Python.

## Project Objectives
- Load an image using Pillow.
- Convert the image into a NumPy array.
- Understand individual RGB colour channels.
- Remove individual colour channels and observe the changes in the image.

## Operations Performed
1. Display the original image.
2. Remove the Red channel (absence of Red colour).
3. Remove the Green channel (absence of Green colour).
4. Remove the Blue channel (absence of Blue colour).

## Technologies Used
- Python
- NumPy
- Pillow
- Matplotlib

## Project Structure
- `images/` – Contains the input image.
- `RGB_Image_Manipulation.py` – Python implementation.

## How to Run
1. Install the required Python libraries.
2. Update the image file path in the Python script according to your computer.
3. Run `RGB_Image_Manipulation.py`.

## Key Learning
Understanding how RGB colour channels represent digital images and how modifying individual channel values affects the final image.
